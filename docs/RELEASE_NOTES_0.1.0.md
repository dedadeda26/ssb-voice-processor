# SSB Voice Processor 0.1.0

> **Make SSB Hifi Again.**

第一个正式版本。给你的 SSB 通联声音做一次彻底的"美容"。

## 下载

- `SSBVoiceProcessor_Setup_0.1.0.exe` — Windows x64 安装包（6.0 MB）

## 这一版有什么

**13 级处理链**
输入增益 → 高通 → 噪声门 → 频谱降噪 → EQ → 多段压缩 → 主压缩 → 饱和 → 去齿音 → SSB 带限 → 自动电平 → 限幅 → 输出增益

**自适应调参**（一键）
点一下，安静 2 秒 + 说话 6 秒，8 秒后全部参数自动配好；不满意可一键撤销。

**DSP 上做过的事**
- 4 阶 Butterworth 带限，默认 90–3100 Hz，系数平滑无咔哒
- Hann 窗 OLA 谱减降噪，按实测噪声轮廓扣底噪
- 多段压缩能量加权自动补偿，切换设置音量不跳
- 4× 过采样饱和，混叠压到 −95 dBc
- 真峰值限幅（1 ms 前视 + 三次插值），末端留 1 dB 余量

**界面**
- 深色界面、中英双语、模块化旋钮面板（简单/高级）
- 频谱瀑布、实时曲线、输入输出电平表
- 托盘常驻：右键可静音 / 原声 / 退出
- 首次启动四页图文教程

## 安装注意

- 程序**默认以管理员身份运行**（Windows 会弹 UAC）：托盘图标与开机自启需要这个权限
- 首次启动会显示教程；按提示选设备 → 跑一次自适应调参即可开始用
- 设置文件保存在安装目录（若不可写则落到 `%APPDATA%\SSBVoiceProcessor`）

## 已知限制

- 仅 Windows x64
- 安装向导界面为中文文本 + Inno 默认英文骨架（官方未提供完整简体中文语言包）
- 需要 48 kHz 左右的声卡；用同一块声卡做输入输出延迟最低

## 验证情况

自动化测试 4 套全部通过：增益斜坡、旁路交叉淡化、带限斜率、多段压缩自动补偿、限幅器前视、饱和混叠、谱减降噪、慢速 AGC、智能调参、UI 布局快照等。
