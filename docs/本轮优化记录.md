## 已完成

### 1. 参数与旁路不再产生咔哒

- 新增 `Source/GainSmoother.h`：块速率跟随 + 逐样本线性插值，音频线程无分配。
- 输入增益、输出增益、饱和（drive / mix / output）、压缩器 makeup、多段 makeup 全部走平滑。实测一次 +12 dB 阶跃的最大相邻样本落差 **0.0013 FS**（未处理时可达 0.75 FS）。
- `DspNode` 新增 `render()`：旁路切换做 8 ms 交叉淡化，音频引擎改为调用 `render()`；稳态下旁路节点仍然完全跳过（不浪费 CPU）。
- 全局旁路同样交叉淡化；新增 `AudioEngine::beginSoftTransition()`，在预设加载 / 风格切换 / 一键智调 / 重置后让输出在 25 ms 内淡入，避免"整链跳变"的爆音。

### 2. 一键智调（把"自动校准"升级为全参数智能）

新增 `Source/SmartTune.h/.cpp`：

1. `extract()` 测量：底噪电平、语音 RMS / 峰值 / 95 分位、峰值因数、信噪比、削波比、有效语音时长、16 段长时平均频谱、低频占比、2–3 kHz 临场感、5–9 kHz 齿音比、300 Hz–3 kHz 频谱斜率。
2. `propose()` 依据测量结果给出**全部 10 个模块**的参数：输入增益、低切、噪声门（门限/深度/时间）、三段 EQ（每个增益限制在 ±4 dB 以内）、多段压缩（三段强度 + 门限）、主压缩（门限由 95 分位推出、比例由峰值因数推出、makeup 由预估衰减推出）、饱和（保守，按峰值因数 2–5 dB）、去齿音（按实测齿音比 35/50/65%）、限幅（热源多留 0.5 dB）、输出增益。
3. **闭环校准电平**：把采集到的语音离线渲染过*真实节点链*（`measureChain()`，遵守各模块旁路状态），按"距限幅上限 11.5 dB"的目标迭代调整输出增益；限幅器吃掉一半以上请求增益时停止，避免"越推越扁"。实测落在目标 ±1 dB 内。
4. **可撤销**：智调前快照全部参数，工具栏出现"撤销智调"按钮，一键恢复（`captureState` / `restoreState`）。
5. **模型接口**：`ParamModel` + `ResidualMlp`（12→16→6，残差式）。模型只能对规则结果施加*有界*修正（输入 ±4 dB、门限 ±8 dB、饱和 ±3 dB…），权重为空时是严格的 no-op——所以现在它不会改变任何结果，将来训练好权重再启用即可，不存在"改坏"的风险。

低切默认值与范围**未改动**（仍是 90 Hz / 60–500 Hz，按你的要求保留），只有当实测低频占比明显偏高时才临时给出 110/130 Hz 的建议值，且完全可逆。

### 3. 带限斜率（默认值与范围不变）

`BandLimitNode` 从 2 阶改为 4 阶巴特沃斯（两个双二阶级联，Q=0.541/1.307），**截止频率默认 90/3100 Hz 与 60–500 / 2000–4000 的可调范围完全保持**。实测 6.2 kHz 处从 −13.0 dB 变为 **−25.6 dB**，通带仍为 0.0 dB。这是抑制邻频溅射的关键一步（饱和器在带限之前）。

### 4. 多段压缩：门限旋钮 + 自动补偿

- 门限从"`-10 - 0.3 × Amount`"的隐藏映射改为**独立旋钮**（−45…−6 dB，默认 −22 dB，与原先 Amount=40 的行为一致），Amount 现在只控制压缩深度。
- 新增**按频段能量加权**的自动 makeup（恢复三段实际拿走的电平），手动 makeup 变成叠加微调。实测 Amount 从 0 到 80，输出电平只差 **0.9 dB**（此前会掉 10 dB 以上）。
- 这也修掉了"Amount 越大越薄越刺"的频谱倾斜来源。

### 5. 限幅器前视

`LimiterNode` 改为 1 ms 前视：增益由前视窗内的**最大幅度**决定，因此衰减在峰值到达输出之前就已经建立。最终硬截断只作为兜底（新增 `getClampCount()` 供测试断言），实测在 +6 dB 过载下**零次兜底**、上限严格保持。

### 6. 显示不再"说谎"

- 新增 `Source/FreqResponse.h`：用与音频路径**同一套系数工厂**算幅频。
  - 注意：`juce::dsp::IIR::ArrayCoefficients` 返回的是**未归一化**的 `{b0,b1,b2,a0,a1,a2}`（与 `Coefficients` 存下来的 `{b0,b1,b2,a1,a2,type}` 不同），第一版把 `a0` 当成了 `a1`，已改正并用教科书数值断言（90 Hz 高通在 45 Hz 应为 −12.3 dB，实测 −12.3 dB；+6 dB 峰值在中心恰好 6.0 dB）。
  - EQ 曲线改成真实低架 + 峰值（**Q 现在真的会改变曲线**）+ 高架；高通曲线改成真实 2 阶响应。
- 压缩器传输曲线按 DSP 里的 soft-knee 公式绘制，不再画直角。
- 竖直电平表红段原本从顶端往下画（−5 dBFS 就像满表），改为贴着当前电平。
- 波形"平滑"原本与同一个环形槽位（约 2.7 秒前）比较，改为沿时间的前一样本。
- 噪声门指示牌的输入电平下限从 −60 dB 改为 −80 dB（门限范围是 −80…−20，之前低于 −60 dB 的门限会永远显示 OPEN）。
- 托盘隐藏后再次启动会**重新显示主窗口**（重写 `anotherInstanceStarted`），不再"看起来像进程死了"。

### 7. 饱和器 4× 过采样

`SaturationNode` 内的 tanh 改到 4 倍采样率上计算（`juce::dsp::Oversampling`，两级 polyphase 半带 IIR），再抽取回设备采样率；dry 路径按过采样器延迟对齐，mix 仍然按设备采样率做（不会因为延迟产生梳状）。
节点按 `blockSize` 分块，因此任意块长度（含测试/离线测量里的 8193、4096 分块）都安全。

实测（2.9 kHz 单音、+24 dB drive、−6 dBFS，1.0–1.6 kHz 带内杂散）：

| 版本 | 带内混叠杂散 |
|---|---|
| 直接 48 kHz 计算 tanh | **−35 dBc** |
| 4× 过采样 | **−95.4 dBc** |

### 8. 状态一致性（本轮新增）

- **总旁路会保存/恢复**：上次关机时处于"原声"，重启不会再偷偷开始处理（`bypass` 写入 UI 设置）。
- **风格下拉框不再是"假状态"**：任何手动改动、加载预设、重置都会把它标成"自定义"，并记住上次选择。
- **删除预设不再静默失败**：在"自定义（未保存）"状态点删除会明确提示"请先选择预设"（之前什么都不发生）。
- **保存同名预设会二次确认**，不再静默覆盖（`PresetManager::presetExists`）。

### 9. 频谱降噪（新增模块）

新增 `Source/Nodes/SpectralNrNode.h/.cpp`，插入到噪声门之后（链路变成 12 个模块，界面图标自动适配，已验证 1000 px 宽度不溢出）。

- 1024 点 FFT、hop 512、Hann 分析窗 + 重叠相加（50% 重叠的 Hann 和恒为 1，增益为 1 时逐样本重建）。
- 噪声谱来自智调采集的前 2 秒静音段（`setNoiseProfile`），没有噪声谱时**立即返回、比特透明、零延迟**。
- 每个频点做谱减：`gain = 1 − 1.6 × 噪声/信号`，钳到「最大衰减」下限（默认 −18 dB），再按「降噪量」百分比与透明结果混合；增益做快降慢升的时间平滑，抑制音乐噪声。
- 关键实现细节：JUCE 的实数 FFT 在 vDSP / IPP / 回退后端对负频率镜像区的使用方式不同，所以正负频点**同步乘同一个实数增益**，否则逆变换会出错。
- 智调根据实测 SNR 自动给降噪量（<12 dB → 70%，<22 → 50%，<35 → 30%，否则 0%）。

实测：无噪声谱时逐样本一致；有噪声谱时对同源噪声 **衰减 13.8 dB**，而 1 kHz 语音带单音几乎不动（<1.5 dB）。

### 10. 慢速自动电平（新增模块）

新增 `Source/Nodes/AutoLevelNode.h/.cpp`，插在 Output Gain 与 Limiter 之间（Limiter 仍是末级）。按块 RMS 以 1–3 s 时间常数微调增益（最大 ±18 dB），静音（< −55 dBFS）时冻结增益，避免"给静音加增益"。实测 −30 dBFS 与 −6 dBFS 输入都收敛到 **−12.3 / −11.5 dBFS**，且单块电平突变时增益移动 < 1 dB（不抽气）。智调会把它的目标设成与闭环输出电平同一个值，二者不打架；`measureChain` 在测量静态电平时会跳过它（它对电平不敏感，测量时必须排除）。

## 已知限制

- 离线渲染测量会在持锁期间占用音频线程约 5–15 ms（最多 4 秒素材 × 11 个节点），一次智调会做 2–4 次；小缓冲下可能听到一次轻微停顿。
- `ResidualMlp` 目前没有训练数据，权重为空 → 严格 no-op。训练方法见 `docs/一键智能校准.md`。
- 饱和器的 4× 过采样引入约 30–40 个样本（<1 ms）的链路延迟；`SaturationNode::getLatencySamples()` 可查询，当前 UI 显示链路总延迟。
- 本轮的验证全部是离线自动化测试（模拟设备），真实声卡/电台链路仍需实机确认。
