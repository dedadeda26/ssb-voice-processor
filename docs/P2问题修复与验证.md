## 关键行为说明

**宏旋钮。** 默认参数下，压缩强度 100% 对应约 −36 dB 阈值、8:1 Ratio、+3 dB Makeup，避免之前的 0 dB 阈值配 +24 dB Makeup。De-Esser 强度提高时降低阈值，而非抬到 0 dB。EQ 音色控制使用低、高频相反方向的调整。已有自定义高级参数作为锚点保留，轻微移动宏只产生小幅连续变化。

**实时处理。** 音频工作缓冲只在设备准备时分配。大于缓冲容量的回调按容量切分，Multi-Band 单独使用时也可分块。系数阶数在 prepare 阶段确定，避免第一次 process 时分配滤波器状态；FFT 同样在准备阶段预热。界面、校准分析、文件读写仍在控制线程分配内存，零分配要求针对音频处理回调。

**频率范围。** 参数上下限作为一个原子快照发布，界面不会分别读到不匹配的上下限。设备配置版本更新后，NodeCard 刷新范围和值。有效数值加载预设时按当前采样率的范围钳制，因此跨采样率加载可能调整频率参数。

**校准流程。** 默认共 8 秒：前 2 秒保持安静，后 6 秒正常说话，覆盖层分阶段提示。质量判断要求语音电平不低于约 −50 dBFS、相对噪声的信噪比至少约 10 dB，并有足够活动时长；明显削波或无效数值会拒绝应用参数。分析帧按采样率保持约 20 ms。输入增益同时参考语音 RMS 与峰值余量。门阈值来自拟应用的前级处理后的噪声 RMS 加 8 dB，并按参数范围限制。总旁路时拒绝开始；单模块旁路选择保留并参与前级电平估计。质量判断采用电平活动启发式，不是语音识别模型，突发噪声仍有误判可能。

**设备设置。** 选择设备类型只编辑待应用选项，不立刻切换声卡。尚未打开的类型仅提供 Default 采样率和缓冲设置，应用成功后显示设备真实支持的选项。失败时恢复之前的有效配置；如果旧设备也无法恢复，错误中包含恢复失败原因。保存失败同样报告并回退。启动找不到保存设备时显示原因、尝试默认设备，同时保留保存的偏好，便于设备重新接入后恢复。

**预设。** 版本 1 为当前格式；缺少版本字段或显式版本 0 的旧格式可迁移。旧版/部分预设缺少的节点和参数以默认值补齐，避免混入上一预设的状态；未知版本、节点、参数或重复节点被拒绝。数值必须有限且能以 float 表示，合法数值按当前范围钳制。保存通过临时文件替换目标；错误反馈保留在 UI。Windows 保留名称包含 COM/LPT 的上标数字变体，规则已对照 [Microsoft 文件命名文档](https://learn.microsoft.com/en-us/windows/win32/fileio/naming-a-file)。

**其他改动。** 预设保存弹窗改用 SafePointer，避免异步回调访问已销毁的主界面；截图测试改为覆盖保存，避免重复运行读到旧 PNG。README 的带宽描述也校正为实际默认 90–3100 Hz 和可调行为。
