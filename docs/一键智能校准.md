# 一键智能校准（Smart Tune）设计与扩展指南

目标：按下"一键智调"后，程序在 8 秒内完成一次全参数设置，达到"开袋即食"——不需要用户懂压缩器、门限和 makeup。

## 流程

```
8 s 采集（前 2 s 保持安静，后 6 s 正常说话）
   │
   ├─ CalibrationAnalysis::analyze()   质量门 + 输入增益 + 门限（原有、已测试的逻辑）
   │     · 静音/稳态噪声/低信噪比/削波/NaN 一律拒绝，且不提交任何参数
   │
   ├─ SmartTune::extract()             特征提取
   │     · 时域：底噪、语音 RMS、95 分位、峰值、峰值因数、SNR、削波比、有效语音时长
   │     · 频域：16 段长时平均谱（1024 点 Hann、50% 重叠、按窗能量归一化）
   │              低频占比、2–3 kHz 临场感、5–9 kHz 齿音比、300 Hz–3 kHz 最小二乘斜率
   │
   ├─ SmartTune::propose()             规则引擎 → 全部 10 个模块的参数
   │     · 输入增益：目标语音 RMS −15 dBFS，受峰值余量约束，范围 [−12, +6]
   │     · 低切：默认 90 Hz 不动；只有低频占比明显偏高时才建议 110/130 Hz
   │     · 噪声门：门限/深度来自质量门，时间常数收紧
   │     · EQ：低频/临场/齿音三段，每段 ±4 dB 以内，绝不"暴力 EQ"
   │     · 多段压缩：强度随峰值因数，门限跟随实测电平
   │     · 主压缩：门限 = 95 分位 − 5 dB，比例由峰值因数 2.5/3.5/5，makeup 由预估衰减
   │     · 饱和：2–5 dB（保守，避免混叠与"糊"）
   │     · 去齿音：按实测齿音比 35 / 50 / 65 %
   │     · 限幅：热源 −2.5 dB，其余 −1.5 dB
   │
   ├─ applySettings() → 持音频锁一次性写入
   │
   ├─ measureChain()                   把采集到的语音离线渲染过真实节点链（≤4 s、4096 分块）
   │     · 遵守各模块的旁路状态，测量 RMS / 峰值 / 限幅前峰值
   │     · 渲染后 reset() 所有节点，避免污染实时状态
   │
   └─ 迭代输出增益：目标 = 限幅上限 − 11.5 dB
         · 限幅器吃掉超过一半请求增益时停止（再推只会更扁）
```

结果以一行摘要回传界面，例如：

```
智调完成：输入 +3.2dB · 低切 110Hz · 门限 -52dB · 压缩 3.5:1 · 饱和 3.5dB ·
齿音 50% · 限幅 -1.5dB · 输出 +2.1dB（预计 -14.8 dBFS RMS，限幅 0.6dB）
```

同时工具栏出现"撤销智调"按钮，一键回到智调前的全部参数（`SmartTune::captureState/restoreState`）。

## 为什么是规则而不是纯神经网络

- 规则可解释、可复现、可单元测试；每个输出都能追到某个测量值。
- 神经网络需要标注数据（"操作员最终会把旋钮停在哪儿"），目前没有。
- 语音链路的输出范围很小，错误代价很高（啸叫、爆音、过调制），不适合让无约束的黑箱直接写参数。

因此模型被设计成**残差修正**：它只能在规则结果上加一个有界偏移。

```cpp
class ParamModel
{
public:
    virtual ~ParamModel() = default;
    virtual void refine(SmartTune::TargetSettings&, const SmartTune::Features&) const = 0;
};
```

`ResidualMlp` 的结构与约束：

| 项 | 值 |
|---|---|
| 输入 | `kModelInputs = 12` 个归一化特征（峰值因数、SNR、RMS、95 分位、斜率、齿音、低频占比、临场感、有效时长、削波比、底噪、当前输入增益） |
| 隐层 | `kHidden = 16`，tanh |
| 输出 | `kOutputs = 6` 个残差，tanh 后有界 |
| 权重数 | `kWeightCount = 12*16 + 16 + 16*6 + 6 = 310` |
| 残差上限 | 输入增益 ±4 dB、门限 ±8 dB、压缩门限 ±8 dB、饱和 ±3 dB、齿音 ±15 %、输出 ±6 dB |
| 空权重时 | 严格 no-op（`hasWeights()` 为假 → `refine()` 直接返回） |

## 如何训练并启用

1. 采集标注：让操作员用普通流程（先智调，再手动微调），记录最终参数与当时的 `Features`。
   只保留"操作员确实动过旋钮"的样本，残差 = 最终值 − 规则值。
2. 归一化输入与上面的 12 维一致，输出做 tanh 前的反变换，用 MSE 训练。
3. 按布局 `w1(12×16) → b1(16) → w2(16×6) → b2(6)` 平铺成 310 个 float。
4. 构造 `SmartTune::ResidualMlp(weights)` 并交给 `AutoCalibrator`（目前它持有 `std::unique_ptr<ParamModel>`，默认是空权重的 `ResidualMlp`）：
   ```cpp
   // AutoCalibrator 构造时
   model = std::make_unique<SmartTune::ResidualMlp>(loadWeightsFromFile(...));
   ```
5. 回归验证：`ssb_priority_tests --opt` 里的 `testSmartTune` 已经检查"残差不超过各自上限"，权重文件不合法时会退回 no-op。

## 需要注意的边界

- 智调会**改写全部模块**，所以撤销是必需的，不要删掉它。
- 采集期间总旁路必须是关闭的（`AutoCalibrator::start` 已检查）。
- 前 2 秒如果有人说话，底噪会被高估 → 门限偏高。这是 8 秒流程的固有限制，界面已在阶段提示里要求"保持安静"。
- 离线测量会占用音频线程 5–15 ms，属于一次性代价；不建议在发射中反复点击。
