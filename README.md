## 这是什么

一个 Windows 桌面程序，把麦克风信号实时处理后送给电台（声卡 → 电台的音频输入）。整条处理链照着 SSB 的带宽特性设计：**90–3100 Hz 收在该收的地方，多余频段一律清掉**，让有限的 2.7 kHz 里全是信息量。

传统做法是买一台语音处理器，或者对着均衡器瞎拧。这个软件把那些东西塞进一个窗口，而且——重点是——**它自己会拧**。

## 能做什么

- **13 级处理链**：输入增益 → 高通 → 噪声门 → 频谱降噪 → EQ → 多段压缩 → 主压缩 → 饱和 → 去齿音 → SSB 带限 → 自动电平 → 限幅 → 输出增益
- **自适应调参**：点一下，安静 2 秒、说话 6 秒，8 秒后全部参数自动配好；不满意一键撤销
- **干净带限**：4 阶 Butterworth 高通 + 低通，默认 90/3100 Hz，边缘不"糊"
- **频谱降噪**：Hann 窗 OLA 谱减法，按实测噪声轮廓扣底噪，不是一刀切
- **多段压缩 + 主压缩**：能量加权自动补偿，换设置时音量不忽大忽小
- **4× 过采样饱和**：谐波不折叠回可听频段（实测混叠 −95 dBc）
- **真峰值限幅**：1 ms 前视 + 三次插值峰值估计，末端留 1 dB 余量，不炸音
- **可视化**：频谱瀑布、实时曲线、输入/输出电平表
- **托盘常驻**：关窗进托盘，右键可静音 / 原声 / 退出
- **中英双语**、深色界面、预设保存

## 怎么用（三步）

1. **装好，打开**
   首次启动有四页小教程。程序默认以管理员身份运行（托盘图标与开机自启需要它）。

2. **选设备**
   设置 → 音频设备 → 选麦克风与输出设备 → 应用。
   推荐 48 kHz、缓冲 256～512；输入输出用同一块声卡延迟最低。

3. **调一次参**
   点「自适应调参」：**前 2 秒别出声**（它在听底噪），**后 6 秒正常说话**。
   结束时自动配好全部模块。之后一般只需调「输出增益」去匹配你的电台输入电平。

嫌吵点 **静音**；想听没处理过的原声点 **原声**。其余随缘。

## 默认音频参数

| 项目 | 默认 | 说明 |
|---|---|---|
| 带限 | 90 – 3100 Hz | SSB 有效话音带宽 |
| 噪声门 | −50 dB / 50 % | 带 120 ms 保持与迟滞 |
| 频谱降噪 | 50 %，最大 −18 dB | 需先跑一次自适应调参采集噪声轮廓 |
| 输出峰值 | ≤ −1 dBFS | 留余量，避免对方端炸音 |

## 从源码构建

需要 CMake、JUCE 9、Visual Studio 2022/2026（MSVC）。

```bat
cmake -S SSBVoiceProcessor -B build -G "Visual Studio 18 2026" -A x64 -DJUCE_DIR=<JUCE 路径> -DSSB_BUILD_TESTS=ON
cmake --build build --config Release
ctest --test-dir build -C Release
```

打安装包（需要 Inno Setup 6）：

```bat
cd SSBVoiceProcessor\Installer
python generate_installer.py
"D:\Dev\InnoSetup\ISCC.exe" installer.iss
```

产物在 `SSBVoiceProcessor\Installer\output\`。
